# Dr. Himanshu Kumar Dwivedi — Academic Website

This is a fully self-contained static GitHub Pages website. The CSS is embedded directly inside each HTML file, so the site will not appear unstyled even if asset paths fail.

## Deployment

1. Create or open the repository `himanshuIITBHU.github.io`.
2. Upload the contents of this folder directly to the repository root.
3. Ensure `index.html` is visible at the root.
4. Go to Settings > Pages > Deploy from a branch > main > /root.
5. Wait a few minutes and visit `https://himanshuIITBHU.github.io`.

If using a project repository, the website will appear at `https://himanshuIITBHU.github.io/<repository-name>/`.
